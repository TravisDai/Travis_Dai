# Johari-Inspired GenAI Reflective System

One canonical system, two public-facing hubs:

- **Reader & Research Companion** — paper-aligned explanation, prompt, workflow, privacy, evaluation boundary, and reproducibility.
- **Workshop & Professional Learning Hub** — live demonstration, workshop activities, facilitator guidance, and participant materials.

Both hubs use the same four interaction functions:

- **Open** — consolidation
- **Blind** — critique / alternative interpretation
- **Hidden** — assumption elicitation
- **Unknown** — ideation

> These labels organise the GenAI interaction. They are not measures of an educator's reflective state or change.

Start here:
- [Reader & Research Companion](docs/readers/index.md)
- [Workshop & Professional Learning Hub](docs/workshop/index.md)

The Reader Companion should remain aligned with the paper version. The Workshop Hub can evolve, but workshop-only extensions should be labelled clearly.
