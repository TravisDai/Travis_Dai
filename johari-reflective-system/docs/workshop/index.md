# Workshop & Professional Learning Hub

[← Back to main page](../)

Use the Johari-inspired four-function routine with colleagues in a demonstration, professional-learning session, or conference workshop.

## Workshop promise

Bring **one real teaching challenge**.

Work through four AI-supported interaction functions.

Critically review the output.

Leave with **one educator-owned next action worth considering**.

## Workshop flow

### 1. Bring a teaching challenge
Examples:
- students repeatedly misunderstand a lab instruction;
- an assessment requirement is interpreted inconsistently;
- a demonstration does not transfer into independent work;
- a tool or environment is creating access problems.

### 2. Prepare de-identified evidence
Use only what is needed: a short lesson/lab/assessment excerpt, the learning objective, one common-error note or feedback excerpt, and relevant constraints.

### 3. Run the four functions
Use the [reference weekly prompt](../../prompts/reference-weekly-prompt.md).

**Open** — What is already clear?  
**Blind** — What alternative interpretation is worth checking?  
**Hidden** — What assumption or constraint should be made explicit?  
**Unknown** — What plausible action is worth considering?

### 4. Challenge the AI
For each useful-looking item:
- What is grounded in evidence?
- Where is the AI interpreting?
- What context is missing?
- Would I accept, modify, reject, or defer this?
- What would I look for if I tried it?

## Suggested live case

**Scenario:** Students complete a technical lab, but several follow instructions mechanically and struggle when a small configuration detail changes.

Supply:
- the intended learning outcome;
- a short lab excerpt;
- one de-identified error pattern.

Then run all four functions and model critical review live.

## Debrief

Ask:
1. Which AI contribution was genuinely useful?
2. Where did the AI overreach or lack context?
3. What would need to be recorded if you wanted to evaluate whether a later action actually came from this interaction?

## Important distinction

Completing the four sections shows that the **workflow operated**. It is not evidence that participants became more reflective, that teaching improved, or that a generated idea was adopted.

For the research design and methodological rationale, visit the [Reader & Research Companion](../readers/).
