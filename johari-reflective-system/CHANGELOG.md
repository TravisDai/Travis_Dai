# Change log

## Two-hub structure

The project now separates two audiences while retaining one canonical system definition.

### Reader & Research Companion
Paper-aligned system definition, prompt, workflow, privacy, human review, and evaluation boundary.

### Workshop & Professional Learning Hub
Demonstration and facilitation materials for colleagues and professional-learning sessions.

### Shared resources
Both hubs use the same four-function architecture, reference prompt, reflection log, and vector figures.

This separation prevents workshop extensions from being mistaken for features or outcomes evaluated in the research paper.
