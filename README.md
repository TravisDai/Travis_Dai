# Fei (Travis) Dai: Academic Homepage

Source for my academic website: **https://travisdai.github.io/Travis_Dai/**

I am a Senior Lecturer in Computing at the Eastern Institute of Technology (EIT), New Zealand. My research focuses on communication-efficient distributed AI training: collective communication, optical and electronic interconnects, and the co-design of algorithms and computing systems. I also work on GenAI-enabled computing education and authentic, AI-aware assessment.

- [onoc-fcnn-allocation](https://github.com/TravisDai/onoc-fcnn-allocation): simulator and reproduction package for core allocation on a ring optical network-on-chip ([Zenodo DOI](https://doi.org/10.5281/zenodo.22904099))

## About this repository

The site is a single static page (`index.html` and `site.css`) served by GitHub Pages from the `main` branch. The visitor map uses `visitor-v4.js` with D3 and TopoJSON in `vendor/`.

The page design started from the [Minimal Light](https://github.com/yaoyao-liu/minimal-light) theme by Yaoyao Liu (CC0). The text, photographs and publication details are my own; please ask before reusing them.
